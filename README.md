# Quản lý bán hàng tại 1 cửa hàng giầy dép thời trang.

Xây dựng phần mềm chỉ phục vụ cho nhân viên (không viết ứng dụng cho người mua)

## Về tài liệu

- Phần 1: Thu thập và phân tích yêu cầu
- Phần 2: Thiết kế sơ đồ lớp (class diagram) + mô tả các ràng buộc
- Phần 3: Sơ dồ CSDL (Database diagram trên HQTCSDL SQLServer) + Mô tả ràng buộc
- Phần 4: Hiện thực (chụp và mô tả các màn hình chính)

## Về chương trình

1. Tối thiểu chương trình bao gồm các chức năng chính: Thêm, xóa, cập nhật, liệt kê (dạng danh sách và chi tiết), tìm kiếm (đơn giản, nâng cao) dữ liệu của các bảng (lưu ý cập nhật, xóa dữ liệu của các bảng có quan hệ).
2. Chương trình xử lý được nghiệp vụ chính: lập hóa đơn bán, xuất được hóa đơn.
3. Xử lý được nghiệp vụ thống kê cơ bản
4. Giao diện thân thiện, sử dụng các phím tắt, tab khi cần thiết. (khuyến kích dùng các control nâng cao, mở rộng…)
5. Phần viết code cần phải dùng Coding Convention cho ngôn ngữ Java.
6. Phải code đúng mô hình 2 hoặc 3 lớp. (Three-Tier Architecture)
